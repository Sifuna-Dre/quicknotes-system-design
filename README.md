# QuickNotes System Design

## Description

QuickNotes System Design is a project that demonstrates how a simple note-taking application can evolve into a scalable online service. The project includes a working API client built using the JSONPlaceholder practice API and a complete set of backend design documents covering API design, data modeling, and system architecture for a production-scale QuickNotes platform serving one million users.

## How to Run the API Client

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server or in a web browser.
4. Click "Load Notes" to retrieve notes from the API.
5. Create and delete notes using the provided interface.

## Features

- Load notes from an API (GET)
- Create notes (POST)
- Delete notes (DELETE)
- Error handling and validation
- Loading, success, error, and empty states
- Backend API design specification
- Database schema design
- Scalable system architecture
